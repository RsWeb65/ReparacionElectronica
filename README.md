# Sistema de Gestión de Reparaciones Electrónicas

Simulación Front-End + Back-End de un sistema para gestionar reparaciones de dispositivos electrónicos.

**Materia:** Sistemas de Información
**Institución:** Universidad de Guanajuato
**Semestre:** Ago-Dic 2026

---

## Descripción

Sistema web que permite a clientes de un taller de electrónica:

- Consultar los servicios de reparación disponibles.
- Solicitar una reparación generando un ticket con dispositivo, marca, modelo y falla.
- Consultar el estado de sus tickets mediante su email.

Y a los técnicos:

- Ver todos los tickets del sistema.
- Actualizar el estado de cada reparación.
